# SKY Work Experience

A React Native mobile application created as part of a work experience project.

The project is built with **React Native** and **Expo**, with a modular structure separating screens, components, contexts, data, assets, and application actions.

## 📱 About

**SKY Work Experience** is a mobile application developed to explore the process of designing and building an application using modern React Native development tools.

The project provides an opportunity to work with:

* React Native
* Expo
* JavaScript
* Reusable React components
* Application state and context
* Screen-based navigation and layouts
* Local project data
* Mobile UI development

## 🛠️ Technologies

| Technology   | Purpose                         |
| ------------ | ------------------------------- |
| React Native | Mobile application framework    |
| Expo         | Development and build platform  |
| JavaScript   | Primary programming language    |
| React        | UI and component architecture   |
| Expo Snack   | Project prototyping and preview |

## 📂 Project Structure


## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

* [Node.js](https://nodejs.org/) installed
* npm installed
* Expo tooling available
* A mobile device, emulator, or simulator

### Installation

Clone the repository:

```bash
git clone https://github.com/CrypticJosh/SKY-Work-Experience.git
```

Navigate into the project:

```bash
cd SKY-Work-Experience
```

Install the dependencies:

```bash
npm install
```

### Running the App

Start the Expo development server:

```bash
npx expo start
```

Expo will provide options for running the application on a connected device, emulator, or simulator.

You can also scan the generated QR code with a compatible mobile device.

## 💻 Development

The main entry point for the application is:

```text
App.js
```

The project is organised into separate directories to make the application easier to develop and maintain.

When adding new functionality, consider placing:

* **UI elements** in `components/`
* **New pages/views** in `screens/`
* **Shared state** in `contexts/`
* **Static or structured information** in `data/`
* **Application operations** in `actions/`
* **Images and other resources** in `assets/`
